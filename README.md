# Izzy — Developer Portfolio

A dark, immersive techno portfolio built with plain HTML, CSS, and JavaScript. It includes an animated perspective hero and uses the Lanyard REST API to display Izzy's live Discord status, avatar, decoration, activity, and supported profile collectibles.

## Run locally

Open `index.html` directly, or run a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Upload all files in this folder to the root of your GitHub Pages repository. The site has no build step and works as a static site.

## Customize

- Personal content: `index.html`
- Colors and layout: `styles.css`
- Discord user ID and live presence: `script.js`
